# Zepto Data & AI Platform

## Project Overview

This project implements a small data platform pipeline using Python, SQLite, SQL, and pandas.

The project covers:

1. Web scraping
2. Data cleaning and transformation
3. SQLite database creation
4. SQL querying
5. Pandas analysis and validation
